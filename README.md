# Student Management System

A React-based frontend project for a student management system, developed during my internship at Onestop.

## 🛠️ Technologies

- React.js
- JavaScript
- Tailwind CSS
- Firebase
- Vite

## ✨ Features

- Student login interface
- Admin login interface
- User authentication flow
- Student dashboard
- User information section
- Report card functionality
- Teacher-related functionality
- Responsive user interface
- React Router-based navigation

## 📌 Project Experience

This project was developed during my professional experience at Onestop. I contributed to the project from its initial development stage and worked on different features and improvements throughout its development.

The public repository contains an early frontend version of the project.
